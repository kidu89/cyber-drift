## 3. Caveats

1. **Hardware / Browser Requirement**: WebGPU requires a compatible modern browser (Chrome 113+, Edge 113+, or Safari 26+ on macOS/iOS) with hardware acceleration enabled. In headless CI environments without GPU passthrough, WebGPU rendering cannot initialize.
2. **Minified Monolith**: `app.js` is a 4 MB pre-bundled file. Directly editing non-trivial algorithms inside `app.js` carries regression risk. The safest and most maintainable approach is creating clean external companion modules (e.g., `missions_hub.js`) that interact with `window.__sf` and the DOM.
3. **Multiplayer vs Free Roam**: While multiplayer structures (`SF_MP`, `ti`) exist in `app.js`, all user requirements target single-player open-world gameplay, missions, and local storage persistence.
